# RootTrace — Evidence-Driven Debugging with IBM Bob

> **Don't just guess the bug. Investigate it. Prove it. Fix it. Verify it.**

RootTrace is an evidence-driven debugging workflow built with **IBM Bob 2.0**.

Instead of immediately asking AI to generate a fix, RootTrace treats debugging as an investigation:

```text
Bug Report
    ↓
Reproduce
    ↓
Collect Evidence
    ↓
Generate Competing Hypotheses
    ↓
Test Hypotheses
    ↓
Confirm Root Cause
    ↓
Apply Minimal Fix
    ↓
Run Regression Tests
    ↓
Generate Debugging Case File
